# Candidate Profile Fields

The editable profile is inspired by the sections visible in the supplied four-page Naukri profile reference. It is an original interface and data model, not an integration with Naukri.

## Resume and headline
- Optional profile photo
- Resume upload (PDF/DOC/DOCX/RTF up to 2 MB)
- Resume headline and profile summary
- Key skills and employment highlights

## Employment and education
- Repeatable employment records: role, company, period, employment type, location, responsibilities/achievements
- Repeatable education records: qualification, institution, period, study type
- IT skills: skill, version, last used, experience duration

## Projects and accomplishments
- Projects and portfolio URLs
- Online professional profiles
- Work samples
- White papers, publications, or journal entries
- Presentations
- Patents
- Certifications and credential links

## Career profile
- Current industry, department, role category, job role
- Desired job type and employment type
- Preferred roles, work locations, salary preference, shift
- Work modes

## Optional personal details
- Gender, marital status, birth date, category, work permit/authorization, address
- Languages and read/write/speak proficiency
- Optional diversity/disability information, military experience, and career-break details

Personal fields remain optional. The application should not include these fields in an outbound job application unless the user deliberately chooses to provide the information in that application. This local starter has one profile and no authentication; it is not safe to expose it as a multi-user internet service yet.
